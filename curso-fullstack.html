Descripción

Aprende a construir aplicaciones web modernas de principio a fin. Desde la maquetación con HTML y CSS hasta el despliegue en la nube, pasando por JavaScript, React y Node.js.

Trabajarás en proyectos reales y construirás un portafolio profesional que te ayudará a conseguir tu primer empleo tech.

¿Qué aprenderás?

  • HTML5 y CSS3 desde cero hasta nivel avanzado
  • JavaScript moderno (ES6+) y TypeScript
  • React para el desarrollo frontend
  • Node.js y Express para el backend
  • Bases de datos: SQL y MongoDB
  • Despliegue de aplicaciones en la nube
  • Control de versiones con Git y GitHub

Requisitos

  • No se requieren conocimientos previos de programación
  • Ordenador con conexión a internet
  • Ganas de aprender y dedicación
